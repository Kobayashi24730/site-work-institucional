# 🏢 Site Work Institucional - Projeto de Estudo

Este projeto é um **site institucional** desenvolvido com **React + TypeScript + Vite**, utilizando **Tailwind CSS** e componentes baseados em **shadcn/ui** (Radix UI).

---

## 🧠 Sobre o Projeto

Este projeto foi desenvolvido com **fins educacionais**, visando:

- Praticar a construção de um site institucional moderno e responsivo
- Explorar a biblioteca de componentes shadcn/ui (Radix UI)
- Estilização utilitária com Tailwind CSS
- Otimização de SEO com React Helmet Async
- Animações de interface com Framer Motion
- Formulários e validação com React Hook Form + Zod
- Escrever testes com Vitest e Playwright

---

## ⚙️ Tecnologias Utilizadas

- **React** + **TypeScript**
- **Vite** — build tool
- **Tailwind CSS** — estilização
- **shadcn/ui** (componentes Radix UI: dialog, dropdown, tabs, tooltip, etc.)
- **React Router DOM** — roteamento
- **React Helmet Async** — gerenciamento de meta tags e SEO
- **Framer Motion** — animações
- **React Hook Form** + **Zod** — formulários e validação
- **TanStack Query** — gerenciamento de dados assíncronos
- **Recharts** — gráficos
- **Vitest** + **Testing Library** — testes unitários
- **Playwright** — testes end-to-end

## ▶️ Como Executar

### 1. Instalar dependências

```bash
npm install
```

### 2. Rodar em modo desenvolvimento

```bash
npm run dev
```

### 3. Gerar build de produção

```bash
npm run build
```

### 4. Visualizar o build

```bash
npm run preview
```

---

## 🧪 Testes

### Testes unitários (Vitest)

```bash
npm run test          # roda os testes uma vez
npm run test:watch    # roda em modo watch
```

### Testes end-to-end (Playwright)

```bash
npx playwright test
```

### Lint

```bash
npm run lint
```
